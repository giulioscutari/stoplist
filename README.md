Tools like Google Calendar are fantastic to organize your day: you can easily set time aside for anything you want, it is as easy as dragging your mouse on the screen. But what if it's the weekend, and you do not want to start your day at a set time? Or maybe something gets delayed, and now everything after that needs to be pushed thirty minutes, an hour later? Well now you have to drag and drop each thing in your calendar. That's not fun.

This app approaches the issue differently: instead of setting a time when a task is supposed to start and end, you only set a duration. Then you start the timer. Taking a break? Simply pause the timer, and the progress stops. It is still rudimentary, and there is more things I want to do with it - you can't sort your tasks at the moment - but it works! Sort of! :D

Implemented with React Native and TailwindCSS.

Availalble at [https://stoplist-iota.vercel.app/](https://stoplist-iota.vercel.app/)
